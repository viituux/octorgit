# Ícones de tecnologias

Paths SVG derivados de Simple Icons 15.0.0 e quatro marcas da versão 11.0.0 (CSS, Oracle, AWS e Azure) (https://simpleicons.org), distribuídos sob CC0-1.0; consulte LICENSE.md. O catálogo contém somente paths de desenho, títulos e cores locais. Algumas cores foram ajustadas para legibilidade sobre branco. Nomes e marcas pertencem aos respectivos titulares; os ícones identificam tecnologias detectadas, sem afiliação ou confirmação de implantação.

Assets são empacotados, não baixados em runtime. Tecnologias sem ícone específico recebem símbolo genérico. Logos não comprovam presença de componente: o parser/evidência decide quais componentes existem.
